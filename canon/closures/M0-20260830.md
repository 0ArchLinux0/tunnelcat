## Key decisions

- Reuse `tailscale.com` data plane; Go for data, Rust only for the M2 novelty layer
- `rustbridge` cgo-gated: `bridge.go` (cgo) + `nocgo.go` (stub). Unblocks 5-platform build.
- Upstream `tailscale/tailcat` not vendored; import and float. Substrate rule holds.
- Orphaned main from upstream history (missing parent object e9f786ee); 0ArchLinux0/tunnelcat has a clean root.
- `bin/release.sh` requires bash 5 (associative arrays).

## Tried, didn't work (so we don't re-try)

- CGO_ENABLED=0 build with cgo package → "build constraints exclude all Go files." Fix: build tags.
- `concat!(...).as_ptr()` for the C string → not NUL-terminated, Go read into adjacent memory, UB checks fired. Fix: `static &[u8] = ... \0`.
- cbindgen for the C header → emitted C++ headers by default. Fix: hand-written header; revisit in M2.
- cgo build cache keyed on C header, not the static lib → after Rust fix, Go kept linking old `.a`. Fix: `bin/rebuild.sh`.
- `tunnelcat dial --port 0` → port 0 not connectable. Fix: default is 12345.
- `git push` to new GitHub repo → "did not receive expected object e9f786ee." Fix: orphan main.

## M1 sub-stepping (the new pattern)

Each sub-step is one branch + one commit + one verify command.

1. `tunnelcat identity init` saves key to `~/.config/tunnelcat/keys/default.private.json`. Verify: file exists, contains Curve25519 key.
2. `tunnelcat identity show` prints pubkey. Verify: stdout starts with `nodekey:`.
3. `tunnelcat contact add <name> <pubkey>` adds to `contacts.yaml`. Verify: file contains the contact; `contact list` shows it.
4. `tunnelcat dial <name>` looks up the contact. Verify: dials with file, errors with "unknown contact" if missing.
5. `tunnelcat --version` reads from a real build, not "dev". Verify: prints `tunnelcat v0.1.X` (set by `-ldflags`).
6. CI workflow runs on every push. Verify: PR raises green check.
7. README has a 5-minute quickstart. Verify: non-author can follow it without asking.
8. Friend can `curl | sh` and connect. Verify: 1 friend does it.

M1 is done when all 8 are green.
