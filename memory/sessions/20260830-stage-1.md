## The actual data-plane call site

The server is 5 lines of meaningful code:

```go
srv := &tailcat.Server{}
srv.OnTCP = func(port uint16) func(net.Conn) {
    return func(c net.Conn) {
        defer c.Close()
        io.Copy(c, c) // echo
    }
}
srv.Start()         // connects to DERP, generates ephemeral key
fmt.Println(srv.ConnBlob())  // prints the tc... token
```

The client is also small:

```go
cl := tailcat.NewClient(tailcat.ConnBlob(token))
conn, err := cl.DialTCPPort(ctx, port)  // brings up tunnel lazily
io.Copy(conn, os.Stdin)
io.Copy(os.Stdout, conn)
```

That's the whole Stage 1 surface. Everything else (`tailscale.com`'s
WireGuard, magicsock, DERP, netstack) is already there.

## What works, end-to-end (verified)

- `tunnelcat up` connects to a public DERP relay (`derp-304`,
  19ms away from this Mac), generates a fresh Curve25519 key,
  creates a WireGuard device in userspace, gets a deterministic
  IPv6 address inside the tunnel, prints a real `tcom...` token.
- `tunnelcat dial <token>` parses the token, generates its
  own keypair, connects to the same DERP relay, sends a Meow
  ping to the server (over DERP), the server replies Meowed,
  both sides run the WireGuard handshake, then disco (UDP
  hole-punching), upgrade to direct P2P, and the client dials
  the server through the tunnel.
- The whole handshake takes about 1 second. The echo round-trip
  is instant.
- Ctrl-C on the server cleanly closes the WireGuard device and
  the DERP connection.
- `TestE2EEchoRoundTrip` runs this whole flow in 1.5s, asserts
  the echo, and cleans up.

## What I haven't done yet (and why)

- **No `tunnelcat push` to GitHub.** `origin` points to
  upstream; the `branch-push` script correctly refused. You
  need to create a GitHub fork and run `bin/setup-fork.sh
  <user>` to back this up remotely.
- **No `tunnelcat identity init`.** That's Stage 2. Without
  it, the server uses an ephemeral key (fine for testing; you
  lose the address if the process restarts). Stage 2 saves a
  stable key to `~/.config/tunnelcat/keys/`.
- **No `--serve` flag like upstream tailcat.** Stage 1 only
  echoes on whatever port the client dials. Stage 6's services
  YAML adds named ports.
- **No SSH or `tailcat --serve=no-auth-ssh` mode.** That comes
  in Stage 6.
- **No coord server, no `tunnelcat status`, no `tunnelcat ssh`.**
  All Stage 3+.

## Bugs I found and fixed while doing this

1. **`--port 0` doesn't work for `dial`.** Port 0 in TCP is
   "any available port" and isn't a valid dial target. Default
   is now `12345`. The flag description was misleading; fixed.
2. **First attempt's stderr got the data plane's log noise.**
   The data plane writes a lot of debug log to stderr by
   default. The user might want to silence it; that's a
   `tailcat.Server.Logf = logger.Discard` for later. For now,
   the log noise is useful (you can see the WireGuard handshake
   happen).
